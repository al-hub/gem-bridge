프로젝트 개요 및 목적 (Project Purpose)

gem-bridge는 모바일 Gemini 앱이나 Google Drive에서 발행한 태스크 명세를 감지하여, 로컬 작업 공간(WSL)의 코드를 자동으로 수정하고 원격 Git 저장소에 Commit & Push까지 수행하는 Google Workspace ↔ Git 자동화 파이프라인 데몬입니다.

모바일 주도 개발
PC 앞이 아니어도 모바일 Gemini를 통해 드라이브에 태스크를 전달하고 Git 커밋 자동 트리거
경량 백그라운드 상주
WSL 내 systemd 데몬으로 상시 구동되어 파일 I/O 이벤트를 실시간 감시 및 즉각 처리
자동 격리 및 아카이빙
처리 완료된 태스크는 타임스탬프와 함께 processed/ 디렉터리로 안전하게 보관

전체 동작 구조 및 아키텍처 (Architecture)

gem-bridge는 외부 서비스/모바일 환경과 로컬 워크스페이스 간의 비동기 메시지 기반 파이프라인으로 작동합니다. 

┌─────────────────────────────────────────────────────────────────────────┐
│                      1. 모바일 / Gemini 클라이언트                      │
│        - 이동 중 태스크 명세 작성 및 Google Drive 폴더 저장             │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ Sync (Google Drive Desktop)
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│              2. 마운트 폴더 감시 (WSL /mnt/g/GeminiBridge/)             │
│   ┌─────────────────────────────────────────────────────────────────┐   │
│   │                 gem-bridge 데몬 (bridge_daemon)                 │   │
│   │   - 파일 이벤트 감시 (Polling Loop / File Watcher)              │   │
│   │   - .gdoc 가상 파일 필터링 및 일반 텍스트 태스크 Parsing       │   │
│   └────────────────────────────────┬────────────────────────────────┘   │
└────────────────────────────────────┼────────────────────────────────────┘
                                     │
            ┌────────────────────────┴────────────────────────┐
            ▼                                                 ▼
┌───────────────────────────────┐                 ┌───────────────────────┐
│  3. 로컬 소스코드 반영        │                 │ 4. Git 자동화 처리    │
│  - workspace 파일 수정/생성   │                 │ - git add / commit    │
│  - 문맥 반영 및 코드 적용     │                 │ - origin main Push    │
└───────────┬───────────────────┘                 └───────────┬───────────┘
            │                                                 │
            └────────────────────────┬────────────────────────┘
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│                    5. 태스크 완결 및 격리 아카이빙                      │
│        - 처리된 태스크 파일을 GeminiBridge/processed/ 이동             │
└─────────────────────────────────────────────────────────────────────────┘
I/O 및 동작 주의 사항: Windows Google Drive 동기화 폴더의 가상 링크 파일(.gdoc)은 WSL I/O 시 [Errno 5]가 발생하므로, 일반 텍스트 태스크 파일(.txt, .md, .json 등)만 감시 대상으로 처리합니다.

설치 및 환경 설정 (Installation & Setup)

1) 사전 준비 사항

  • Windows WSL2 (Ubuntu Linux) 환경
  • Google Drive for Desktop 설치 및 마운트 (예: /mnt/g/My Drive/GeminiBridge/)
  • Python 3.10+ 및 Git 인증 설정 (SSH Key 또는 Personal Access Token)

2) 저장소 클론 및 종속성 설치

git clone https://github.com/al-hub/gem-bridge.git ~/workspace/gem-bridge
cd ~/workspace/gem-bridge
pip install -r requirements.txt

3) 설정 파일 작성 및 systemd 데몬 등록

# 1. 설정 파일 (config.json) 생성 및 감시 경로 지정
cp config.example.json config.json

# 2. systemd 서비스 등록
sudo cp gem-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gem-bridge.service

# 3. 구동 상태 및 로그 확인
sudo systemctl status gem-bridge.service
journalctl -u gem-bridge.service -f

사용 방법 (Usage)

  1. 태스크 명세 작성: 모바일 스마트폰이나 웹 브라우저의 Google Drive GeminiBridge/ 폴더에 수행할 작업 명세 파일(예: task_001.txt)을 생성합니다.
  2. 자동 감지 및 실행: 백그라운드 상주 중인 gem-bridge 데몬이 파일 작성을 자동 감지하고 로컬 작업 공간의 코드를 수정합니다.
  3. Git 커밋 및 Push: 변경 내용이 확인되면 데몬이 Git 커밋 메시지를 생성하여 원격 저장소로 자동 Push합니다.
  4. 아카이빙 확인: 처리가 완료된 태스크 파일은 GeminiBridge/processed/ 폴더로 자동 이동됩니다.

업데이트 및 삭제 방법 (Update & Uninstall)

코드 업데이트 (Update)

cd ~/workspace/gem-bridge
git pull origin main
pip install -r requirements.txt
sudo systemctl restart gem-bridge.service

서비스 제거 및 삭제 (Uninstall)

# 1. systemd 서비스 중지 및 비활성화
sudo systemctl stop gem-bridge.service
sudo systemctl disable gem-bridge.service

# 2. 서비스 파일 삭제 및 데몬 리로드
sudo rm /etc/systemd/system/gem-bridge.service
sudo systemctl daemon-reload

# 3. 프로젝트 디렉터리 제거 (선택 사항)
rm -rf ~/workspace/gem-bridge
