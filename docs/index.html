프로젝트 개요 및 목적 (Project Purpose)

gem-bridge는 모바일 Gemini 앱(Google Tasks 확장 프로그램) 및 스마트폰 Google Tasks 앱에서 발행된 태스크 명세를 실시간 감지하여, 로컬 워크스페이스(WSL2/Linux) 환경의 코드를 안전하게 반영하고 원격 Git 저장소에 자동 Commit & Push를 수행하는 Google Tasks API 기반 비동기 자동화 파이프라인 데몬입니다.

Google Tasks 전환
기존 Google Drive 가상 파일(.gdoc)의 WSL I/O 동기화 병목과 인코딩 지연 문제를 근본적으로 극복하기 위해 공식 Tasks API 기반의 실시간 트래킹 구조로 전환되었습니다.
모바일 최적화 & Gemini 연동
스마트폰 구글 할 일 위젯, 캘린더 연동 및 Google Gemini 앱에 "할 일 추가해줘"라고 직접 음성/텍스트로 명령하여 신속히 코드를 변경할 수 있습니다.
고신뢰성 아키텍처
작업 반영 성공 시 해당 태스크를 '완료(Completed)' 상태로 자동 토글하여 멱등성을 완벽히 보장하고, 변경된 코드 스냅샷을 원격 저장소에 즉각 Push합니다.

전체 동작 구조 및 아키텍처 (Architecture)

gem-bridge는 모바일 Google Tasks 입력을 기점으로 데몬의 폴링, 코드 주입 엔진, Git 형상 제어 컴포넌트로 구성된 이벤트 루프 기반 파이프라인으로 동작합니다.

Google Tasks API 전환의 이점: 파일 동기화 지연 및 드라이브 동기화 오버헤드가 없으며, 파일 시스템 쓰기 오류(I/O Error)가 발생하지 않아 모바일-데몬 간 응답 속도가 대폭 향상되었습니다.

설치 및 환경 설정 (Installation & Setup)

1) 사전 준비 사항

  • 운영체제: Windows WSL2 (Ubuntu 20.04/22.04 LTS 이상) 또는 Native Linux
  • Google API 활성화: Google Cloud Console에서 Google Tasks API 활성화 및 Desktop 애플리케이션 유형의 OAuth 클라이언트 자격증명 생성
  • 자격증명 파일 보관: 다운로드한 JSON 파일을 프로젝트 루트 디렉터리에 credentials.json으로 저장

2) 소스 클론 및 종속성 설치

# 저장소 클론
git clone https://github.com/al-hub/gem-bridge.git ~/workspace/gem-bridge
cd ~/workspace/gem-bridge

# Google API 종속 라이브러리 및 패키지 설치
pip install -r requirements.txt

3) 설정 파일 작성

config.json 파일을 프로젝트 루트 디렉터리에 생성하고 아래와 같이 타깃 저장소 경로와 폴링 주기를 기입합니다.

{
  "workspace_path": "/home/user/workspace/target-project",
  "polling_interval_seconds": 15,
  "default_branch": "main",
  "task_list_id": "@default"
}

4) 최초 구동 및 OAuth 최초 인증

# 터미널에서 최초 직접 실행하여 웹 브라우저를 통한 Google Tasks 권한 부여 완료
python src/main.py

# 인증이 정상 완료되면 프로젝트 루트에 token.json 파일이 자동으로 생성됩니다.

5) systemd 백그라운드 서비스 등록

# 서비스 파일 등록 및 시작
sudo cp gem-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gem-bridge.service

# 서비스 상태 확인 및 로그 추적
sudo systemctl status gem-bridge.service
journalctl -u gem-bridge.service -f

모바일 사용법 및 실전 가이드 (Mobile Usage Guide)

모바일 환경에서 번거로운 코드 타이핑 없이 스마트폰 Google Tasks 앱이나 Google Gemini(할 일 확장 프로그램)를 통해 안전하게 수정사항을 코드에 반영할 수 있습니다.

1) 작업 명세 포맷

데몬이 태스크를 정상 수집하고 파싱하기 위해 반드시 아래 양식을 준수해야 합니다.

  • 제목: [gem-bridge] 대상_파일_경로 (예: [gem-bridge] src/utils.py)
  • 본문 (메모): 수정 및 반영할 코드 조각 또는 상세 동작 지시사항

2) 스마트폰 구글 할 일(Google Tasks) 앱에서 작성

  1. 구글 할 일 앱을 열고 신규 태스크를 생성합니다.
  2. 제목에 [gem-bridge] src/index.js와 같이 타깃 파일 상대 경로를 명시합니다.
  3. 하단 메모(Details)란에 적용할 소스코드를 완전히 채워넣은 후 저장합니다.
  4. 잠시 후 데몬이 해당 태스크를 가공하여 Git Push 후 태스크를 자동으로 완료됨 처리합니다.

3) 모바일 Google Gemini 앱 음성/텍스트 연동

Gemini 앱 연동 꿀팁: Gemini 앱 설정에서 "Google Workspace 확장 프로그램(Tasks)"을 활성화하세요. 
사용자: "내 구글 할 일 목록에 제목은 '[gem-bridge] docs/guide.md'로 하고, 메모에는 '### 업데이트 사항\n- Tasks 연동 최적화 완료'라고 추가해줘."
Gemini: "네, 요청하신 내용을 Google Tasks에 등록했습니다."

유지보수 및 데몬 제어 (Maintenance & Operations)

1) 데몬 중단 및 상태 제어

# 데몬 서비스 일시 중지
sudo systemctl stop gem-bridge.service

# 데몬 재시작 (소스 수정이나 설정 변경 반영 시)
sudo systemctl restart gem-bridge.service

2) 최신 변경사항 업데이트

cd ~/workspace/gem-bridge
git pull origin main
pip install -r requirements.txt
sudo systemctl restart gem-bridge.service

3) 완전히 삭제하기 (Uninstall)

# systemd 서비스 정지 및 영구 등록 해제
sudo systemctl stop gem-bridge.service
sudo systemctl disable gem-bridge.service

# 정의 파일 및 토큰 인증 정보 삭제
sudo rm /etc/systemd/system/gem-bridge.service
sudo systemctl daemon-reload
rm -f ~/workspace/gem-bridge/token.json

# 가상환경 및 소스 디렉터리 정리
rm -rf ~/workspace/gem-bridge
