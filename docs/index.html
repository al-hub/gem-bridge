프로젝트 개요 및 목적

gem-bridge는 모바일 Gemini 앱이나 Google Drive에서 발행한 태스크 명세를 감지하여, 로컬 작업 공간(WSL)의 코드를 자동으로 수정하고 원격 Git 저장소에 Commit & Push까지 수행하는 Google Workspace ↔ Git 자동화 파이프라인 데몬입니다.

모바일 주도 개발
PC 앞이 아니어도 모바일 Gemini를 통해 드라이브에 태스크를 전달하고 Git 커밋 자동 트리거
경량 백그라운드 상주
WSL 내 systemd 데몬으로 상시 구동되어 파일 I/O 이벤트를 실시간 감시 및 즉각 처리
자동 격리 및 아카이빙
처리 완료된 태스크는 타임스탬프와 함께 processed/ 디렉터리로 안전하게 보관

동작 원리 (Architecture)

[사용자 / 모바일 Gemini] ──(작업 생성)──> [Google Drive: GeminiBridge/]
                                                │
                                                ▼ (폴링 감시)
                                      [bridge_daemon (WSL)]
                                                │
                      ┌─────────────────────────┴─────────────────────────┐
                      ▼                                                   ▼
           [1. 로컬 파일 수정/생성]                              [2. Git Commit & Push]
           workspace/gem-bridge/...                              GitHub 원격 저장소
                      │                                                   │
                      └─────────────────────────┬─────────────────────────┘
                                                ▼
                                   [3. processed/ 로 이동 완료]
I/O 주의 사항: Windows Google Drive 동기화 폴더의 가상 링크 파일(.gdoc)은 WSL I/O 시 [Errno 5]가 발생하므로, 일반 텍스트 태스크 파일만 감시 대상으로 처리합니다.

준비 및 설치 (Setup)

1) 사전 준비 사항

  • Windows WSL2 (Ubuntu Linux)
  • Google Drive for Desktop (드라이브가 /mnt/g/ 등에 마운트됨)
  • Python 3.10+ 및 Git 인증 (SSH 키 또는 PAT)

2) 저장소 클론 및 종속성 설치

git clone git@github.com:al-hub/gem-bridge.git ~/workspace/gem-bridge
cd ~/workspace/gem-bridge
pip install -r requirements.txt

3) systemd 백그라운드 서비스 등록

sudo cp gem-bridge.service /etc/systemd/system/
sudo systemctl daemon-reload
sudo systemctl enable --now gem-bridge.service


# 구동 상태 확인
sudo systemctl status gem-bridge.service

실제 사용법 (Usage)

Google Drive 감시 폴더(GeminiBridge/)에 태스크 명세를 넣으면 데몬이 즉시 감지하여 자동 커밋합니다.

유지보수 (Update & Uninstall)

코드 업데이트 (Update)

cd ~/workspace/gem-bridge
git pull origin main
sudo systemctl restart gem-bridge.service

서비스 제거 (Uninstall)

sudo systemctl stop gem-bridge.service
sudo systemctl disable gem-bridge.service
sudo rm /etc/systemd/system/gem-bridge.service
sudo systemctl daemon-reload
